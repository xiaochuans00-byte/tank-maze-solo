# 坦克动荡 · 单人版

[点击直接玩](https://xiaochuans00-byte.github.io/tank-maze-solo/)

随机迷宫、反弹炮弹、电脑对手和回合计分，纯静态网页，通过 GitHub Pages 托管。打开网页后点击“进入战场”即可开始，无需安装。

- WASD 或方向键：前进、后退、转向。
- Q、空格或 Enter：开火。
- P：暂停或继续；R：新比赛。
- 手机可用页面下方的触屏按钮。

可选先赢 5 / 7 / 10 回合，补给包括速射、散射和护盾。炮弹会反弹并击中自己。

## 托管与源码

GitHub Pages 使用 main 分支根目录，无需构建或后端。直接修改 HTML、CSS 和 JavaScript 后推送即可更新页面。

这是基于 Tank Trouble 核心玩法的非官方独立实现，包含独立 Canvas 画面与程序合成音效，不包含原版打包代码、美术或声音。

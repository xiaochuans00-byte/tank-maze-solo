# 坦克动荡 · 单人版

[点击直接玩](https://xiaochuans00-byte.github.io/tank-maze-solo/)

随机迷宫、反弹炮弹、电脑对手和回合计分，纯静态网页，通过 GitHub Pages 托管。打开网页后点击“进入战场”即可开始，无需安装。

- WASD 或方向键：前进、后退、转向。
- Q、空格或 Enter：开火。
- P：暂停或继续；R：新比赛。
- 手机可用页面下方的触屏按钮。

可选先赢 5 / 7 / 10 回合，补给包括速射、散射和护盾。炮弹会反弹并击中自己。

## 托管与源码

GitHub Pages 使用 main 分支根目录，无需构建或后端。直接修改 HTML、CSS 和 JavaScript 后推送即可更新页面。

这是基于 Tank Trouble 核心玩法的非官方独立实现，包含独立 Canvas 画面与程序合成音效，不包含原版打包代码、美术或声音。

## 游玩统计

[打开统计看板](https://tank-maze-stats.prettybell11.chatgpt.site/)（仅游戏所有者使用 ChatGPT 登录后可查看）。游戏页底部也提供入口。

按北京时间统计每日去重玩家、开局次数、有效游玩时长、访问次数和设备占比。点击新比赛或重开计一次开局，自动开始下一回合不计；暂停和切换到后台不计时。

游戏继续托管于 GitHub Pages；匿名数据由 Sites 上的独立 D1 后端汇总，保存近 90 天，看板展示近 30 天。不保存 IP、姓名、原始浏览器标识或完整 User-Agent。匿名标识按天变化，人数属于浏览器估算。遵循浏览器 DNT / GPC，也可在页底关闭统计。历史数据无法补记，断网和拦截统计会导致少计。

`node --test test-analytics.cjs` 验证客户端累计上报、暂停计时、退出统计与跨天处理。`analytics.js` 不含服务器密钥；后台源码由 Sites 项目管理。
